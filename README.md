# МатРесурс — простой сайт на C#

Учебная **информационная система учёта материальных ресурсов предприятия**, разработанная на **C# и Blazor WebAssembly (.NET 10)**. Открывается по ссылке на GitHub Pages, как обычный веб-сайт. На ноутбуке колледжа ничего устанавливать не нужно.

## Что умеет

- Показывает общую стоимость и текущие остатки на главной странице.
- Добавляет и редактирует материалы (название, единица измерения, цена, минимальный остаток).
- Оформляет приход и расход материалов, не допускает отрицательного остатка.
- Сохраняет историю движений.
- Показывает отчёт по остаткам и позволяет скачать таблицу CSV.
- Содержит демонстрационные материалы и кнопку сброса для защиты.

## Из чего состоит

- `Pages/Dashboard.razor` — основные экраны и логика кнопок на **C#**.
- `Pages/MaterialTable.razor` — таблица материалов.
- `Models/Inventory.cs` — C#-модели и демонстрационные данные.
- `wwwroot/css/site.css` — оформление.
- `wwwroot/js/storage.js` — **небольшой служебный JavaScript**, только чтение/запись браузерного хранилища и скачивание CSV.
- `.github/workflows/publish.yml` — бесплатная сборка C#-сайта и автоматическая публикация на GitHub Pages.

## Как получить интернет-ссылку через GitHub (без установки программ)

1. В своём аккаунте GitHub создай **новый открытый репозиторий** с названием, например, `matresurs`. Добавь его пустым, **без README, .gitignore, лицензии**, чтобы можно было загрузить весь комплект.
2. Распакуй ZIP-архив с этим проектом **на личном компьютере**.
3. На странице нового репозитория выбери **uploading an existing file** или **Add file → Upload files**. Перетащи **содержимое** папки проекта, включая папку `.github`, а не сам ZIP. Подтверди **Commit changes**.
4. Перейди **Settings → Pages**, в разделе **Build and deployment** установи **Source: GitHub Actions**.
5. Открой вкладку **Actions**, найди **Publish CSharp site to GitHub Pages** и дождись завершения задания с зелёной галочкой. Если оно ещё не запускалось, выбери **Run workflow**.
6. Вернись в **Settings → Pages**. Там появится ссылка вида `https://ИМЯ-ПОЛЬЗОВАТЕЛЯ.github.io/matresurs/`. Она откроется с ноутбука колледжа через обычный браузер.

**Важно**: GitHub Pages не запускает обычные ASP.NET Core серверы. В этом проекте весь основной код выполняется на C# **в браузере** посредством Blazor WebAssembly. GitHub Actions собирает его на сервере GitHub и публикует готовые файлы автоматически. Не нужно ставить .NET SDK ни в колледже, ни на своём устройстве для этой схемы.

### Если GitHub не запускает сборку

- Убедись, что файл `.github/workflows/publish.yml` действительно в репозитории (GitHub может скрывать папки, начинающиеся с точки, при просмотре Windows).
- Проверь **Settings → Actions → General**, что разрешены Actions.
- Проверь **Settings → Pages → GitHub Actions**, а также журнал вкладки Actions.
- Убедись, что репозиторий называется `matresurs`, или используй фактическое имя: workflow автоматически определяет путь из названия репозитория.

## Как показать работу преподавателю

1. Открой ссылку, зайди в **Материалы** и добавь позицию «Скобы канцелярские» (цена 60 ₽, минимум 2).
2. Перейди в **Приход и расход**, выбери новую позицию, введи **10** и нажми **Сохранить операцию**.
3. Переключи тип на **Расход**, введи **3** — остаток станет **7**.
4. В **Истории** покажи обе операции. В **Отчёте** покажи остаток и выгрузи CSV.
5. Перед следующей защитой можно нажать **Сбросить демонстрацию**.

## Где сохраняются данные

GitHub Pages — статический хостинг и **не имеет серверной базы данных**. Данные сохраняются в `localStorage` браузера на каждом устройстве **отдельно**. Это подходит для демонстрационной курсовой, но **не** для реального совместного учёта предприятия. Данные с личного компьютера не появятся на колледжном автоматически; на новом компьютере показываются исходные демонстрационные записи.

Используй для показа только **учебные/вымышленные** сведения. На общественном компьютере лучше использовать гостевой режим браузера; после завершения показа закрыть гостевую сессию.

## Проверка локально при наличии .NET SDK (не обязательна для GitHub Pages)

```bash
dotnet restore
dotnet run
```

Проект ориентирован на .NET 10. Автоматическая сборка происходит средствами GitHub Actions. Без запущенного GitHub Actions результат успешной сборки не подтверждён.

## Важно для пояснительной записки

Документация, которая раньше описывала ASP.NET Core + SQLite, **не соответствует** этому варианту. Для окончательной сдачи нужно описывать **Blazor WebAssembly + localStorage** и отметить ограничения отсутствия общего серверного хранилища.

# МатРесурс - учебная информационная система на C#

Сайт на **C# / Blazor WebAssembly (.NET 10)**

**Ссылка на сайт:** https://viktorialantuh.github.io/matresurs/

## Внешний вид и автор работы

Главная страница оформлена в сине-белом стиле: **горизонтальное верхнее меню**, градиентный блок с кнопками и карточки разделов.

## Как устроен сайт

- **Главная** - сколько материалов на складе и какова общая стоимость.
- **Материалы** - добавление, редактирование во всплывающем окне, удаление с подтверждением и поиск.
- **Приход и расход** - поступление и выдача со склада.
- **История** - журнал операций.
- **Отчёт** - остатки и скачивание CSV.

| Путь | Что в нём |
| --- | --- |
| `данные материалов и операций/` | Классы C#, хранящие сведения о материалах и операциях |
| `экраны и логика сайта/` | Экраны сайта и обработка нажатий на кнопки |
| `стили/` | Настройка внешнего вида (CSS) |
| `Скрипты( сохранение данных и скачивание отчётов)/` | Небольшой JavaScript для сохранения данных и скачивания CSV |

**Как подключаются стили и скрипты?** Исходные CSS и JavaScript  находятся в четырёх  папках на верхнем уровне репозитория. Перед сборкой GitHub Actions автоматически копирует их во временную папку `wwwroot`, чтобы браузер мог их получить. 


## Понятная карта исходного кода

| Файл | Для чего нужен |
| --- | --- |
| `Program.cs` | Запускает приложение C# |
| `App.razor` | Подключает главный экран |
| `_Imports.razor` | Общие библиотеки компонентов |
| `данные материалов и операций/Inventory.cs` | Классы `Material`, `StockOperation`, `InventoryData` |
| `экраны и логика сайта/Dashboard.razor` | Главные экраны, приход, расход и формирование отчёта |
| `экраны и логика сайта/MaterialTable.razor` | Таблица материалов |
| `wwwroot/index.html` | Первая HTML-страница, загружает приложение Blazor |
| `стили/site.css` | Цвета, кнопки, таблицы и адаптация под мобильный экран |
| `Скрипты( сохранение данных и скачивание отчётов)/storage.js` | Чтение и запись `localStorage`, скачивание CSV |
| `MatResurs.csproj` | Настройки проекта .NET |
| `.github/workflows/publish.yml` | Сборка и публикация сайта через GitHub |


## Принцип работы программы

1. Браузер открывает файл `wwwroot/index.html`.
2. Blazor запускает программу на C# и открывает `Dashboard.razor`.
3. Модели в `Inventory.cs` хранят список материалов и историю операций.
4. При приходе количество увеличивается, при расходе уменьшается. Списать больше остатка нельзя.
5. После изменения система сохраняет данные в браузере через `storage.js`.
6. На странице «Отчёт» можно скачать остатки в формате CSV.

**Важное ограничение:** это учебный сайт на бесплатном GitHub Pages, без серверной базы. Данные `localStorage` существуют отдельно на каждом устройстве.

# МатРесурс — учебная информационная система на C#

Сайт на **C# / Blazor WebAssembly (.NET 10)**, который открывается в браузере без установки программ на ноутбуке колледжа.

**Ссылка на сайт:** https://viktorialantuh.github.io/matresurs/

## Как устроен сайт

- **Главная** — сколько материалов на складе и какова общая стоимость.
- **Материалы** — добавление, редактирование и поиск.
- **Приход и расход** — поступление и выдача со склада.
- **История** — журнал операций.
- **Отчёт** — остатки и скачивание CSV.

Пункт «Оформление» удалён. Страница содержит только функции учёта материалов.

## Папки с понятными русскими названиями

| Путь | Что в нём |
| --- | --- |
| `Модели/` | Классы C#, хранящие сведения о материалах и операциях |
| `Страницы/` | Экраны сайта и обработка нажатий на кнопки |
| `wwwroot/Стили/` | Настройка внешнего вида (CSS) |
| `wwwroot/Скрипты/` | Небольшой JavaScript для сохранения данных и скачивания CSV |

**Почему некоторые папки остались по-английски?** `wwwroot` — обязательное имя каталога статических файлов Blazor, а `.github/workflows` — обязательное расположение файлов автоматической публикации GitHub. Если их переименовать, сайт перестанет работать. `bin` и `obj` также создаются системой автоматически.

Названия классов и пространств имён, например `MatResurs.Models` и `MatResurs.Pages`, сохранены на английском, чтобы не ломать связи программы. **Названия папок при этом русские.**

## Понятная карта исходного кода

| Файл | Для чего нужен |
| --- | --- |
| `Program.cs` | Запускает приложение C# |
| `App.razor` | Подключает главный экран |
| `_Imports.razor` | Общие библиотеки компонентов |
| `Модели/Inventory.cs` | Классы `Material`, `StockOperation`, `InventoryData` |
| `Страницы/Dashboard.razor` | Главные экраны, приход, расход и формирование отчёта |
| `Страницы/MaterialTable.razor` | Таблица материалов |
| `wwwroot/index.html` | Первая HTML-страница, загружает приложение Blazor |
| `wwwroot/Стили/site.css` | Цвета, кнопки, таблицы и адаптация под мобильный экран |
| `wwwroot/Скрипты/storage.js` | Чтение и запись `localStorage`, скачивание CSV |
| `MatResurs.csproj` | Настройки проекта .NET |
| `.github/workflows/publish.yml` | Сборка и публикация сайта через GitHub |

Во **всех основных файлах исходного кода добавлены комментарии по-русски**, объясняющие, что делает каждый блок и важные методы.

## Принцип работы программы

1. Браузер открывает файл `wwwroot/index.html`.
2. Blazor запускает программу на C# и открывает `Dashboard.razor`.
3. Модели в `Inventory.cs` хранят список материалов и историю операций.
4. При приходе количество увеличивается, при расходе уменьшается. Списать больше остатка нельзя.
5. После изменения система сохраняет данные в браузере через `storage.js`.
6. На странице «Отчёт» можно скачать остатки в формате CSV.

**Важное ограничение:** это учебный сайт на бесплатном GitHub Pages, без серверной базы. Данные `localStorage` существуют отдельно на каждом устройстве. При открытии сайта в колледже отображаются демонстрационные материалы.

## Как показать работу преподавателю

1. В разделе «Материалы» добавь «Скобы канцелярские» с ценой 60 ₽ и минимумом 2.
2. В разделе «Приход и расход» оформи приход 10 штук.
3. Оформи расход 3 штук. Должно остаться 7 штук.
4. Покажи новую запись в «Истории».
5. Открой «Отчёт» и скачай CSV.

## Как редактировать исходники

Открой https://github.com/viktorialantuh/matresurs, нажми клавишу **точка (.)** и выбери нужный файл слева. Изменения можно сохранить через **Source Control → Commit & Push**. GitHub автоматически соберёт обновлённый C#-сайт. Программы на ноутбук колледжа устанавливать не нужно.

Перед сдачей курсовой проверь, что пояснительная записка описывает **Blazor WebAssembly и localStorage**, а не старые версии на Windows Forms или SQLite.

# МатРесурс - учебная информационная система на C#

Сайт на **C# / Blazor WebAssembly (.NET 10)**

**Ссылка на сайт:** https://viktorialantuh.github.io/matresurs/

## Как устроен сайт

- **Главная** - сколько материалов на складе и какова общая стоимость.
- **Материалы** - добавление, редактирование во всплывающем окне, удаление с подтверждением и поиск.
- **Приход и расход** - поступление и выдача со склада.
- **История** - журнал операций.
- **Отчёт** - остатки и скачивание отчета.

| Путь | Что в нём |
| --- | --- |
| `данные материалов и операций/` | Классы C#, хранящие сведения о материалах и операциях |
| `экраны и логика сайта/` | Экраны сайта и обработка нажатий на кнопки |
| `стили/` | Настройка внешнего вида (CSS) |
| `Скрипты( сохранение данных и скачивание отчётов)/` | Небольшой JavaScript для сохранения данных и скачивания Excel (.xlsx) |

**Как подключаются стили и скрипты?** Исходные CSS и JavaScript  находятся в четырёх  папках на верхнем уровне репозитория. Перед сборкой GitHub Actions автоматически копирует их во временную папку `wwwroot`, чтобы браузер мог их получить. 

## Понятная карта исходного кода

| Файл | Для чего нужен |
| --- | --- |
| `ЗапускПрограммы.cs` | Запускает приложение C# |

| `_Imports.razor` | Общие библиотеки компонентов |
| `данные материалов и операций/ДанныеСклада.cs` | Классы `Material`, `StockOperation`, `InventoryData` |
| `экраны и логика сайта/ГлавныйЭкран.razor` | Главные экраны, приход, расход и формирование отчёта |

| `wwwroot/index.html` | Первая HTML-страница, загружает приложение Blazor |

| `Скрипты( сохранение данных и скачивание отчётов)/СохранениеИОтчёты.js` | Чтение и запись `localStorage`, скачивание Excel (.xlsx) |
| `MatResurs.csproj` | Настройки проекта .NET |
| `.github/workflows/publish.yml` | Сборка и публикация сайта через GitHub |


## Принцип работы программы

1. Браузер открывает файл `wwwroot/index.html`.
2. Blazor запускает программу на C# и открывает `ГлавныйЭкран.razor`.
3. Модели в `ДанныеСклада.cs` хранят список материалов и историю операций.
4. При приходе количество увеличивается, при расходе уменьшается. Списать больше остатка нельзя.
5. После изменения система сохраняет данные в браузере через `СохранениеИОтчёты.js`.
6. На странице «Отчёт» можно скачать остатки в формате Excel (.xlsx).

**Важное ограничение:** это учебный сайт на бесплатном GitHub Pages, без серверной базы. Данные `localStorage` существуют отдельно на каждом устройстве. 



## Служебные файлы

`App.razor`, `_Imports.razor`, `MatResurs.csproj`, `wwwroot/index.html` и `.github/workflows/publish.yml` оставлены с техническими именами, чтобы не нарушить сборку и публикацию. Они пояснены в таблице выше.

## Оформление интерфейса

Оформление спокойное и простое: серо-белый фон, тёмно-синие заголовки, обычные прямоугольные кнопки и светлые рабочие карточки. Без градиентов и без значков в меню.

Пункты меню оставлены увеличенными для удобства. В главной части и рабочих разделах остаются небольшие тематические иллюстрации.
